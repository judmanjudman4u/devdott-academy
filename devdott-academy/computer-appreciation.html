Introduction :

This course is designed for complete beginners with little or no previous computer experience. Students will learn how to operate a computer, navigate the Windows environment, manage files, use essential software, browse the internet, and perform everyday digital tasks confidently.

Computer Fundamentals and Digital Literacy:

Learn the basics of computer operation, including computer hardware, software, Windows navigation, keyboard skills, typing, file management, and basic computer maintenance. This course is ideal for complete beginners who want to develop confidence using a computer.

Microsoft Office Productivity Skills :

Develop practical skills in using essential Microsoft Office applications. Learn how to create and format documents with Microsoft Word, organize information and perform calculations with Microsoft Excel, and create professional presentations with Microsoft PowerPoint.

Internet, Email and Online Productivity :

Learn how to navigate the internet, search for information, create and manage email accounts, send attachments, download files, use cloud storage, participate in online meetings, and practise safe internet habits. Gain the digital skills needed for modern workplaces, education, and business.
